# Knight Bewitched Enhanced Edition 繁體中文

適用於 Windows Steam 強化版 v2.00。Steam 安裝目錄中的原版與強化版各有一個 `Game.exe`，請從 `Knight Bewitched Enhanced Edition` 子目錄啟動。

- [繁中校對工作表](Knight%20Bewitched%20Enhanced%20Edition%20-%20繁中校對工作表.xlsx) 收錄 8,878 筆英文原文、目前譯文及其來源位置。直接修訂 D 欄，可使用校對狀態與備註追蹤進度。
- [繁體中文補丁](Knight_Bewitched_Enhanced_zhTW_patch.zip) 包含目前套用的 229 個檔案與安裝、還原腳本。請完整解壓縮後依照[安裝說明](patch/README.md)操作。

共通文字沿用原版譯文。強化版新增或改寫的文字使用本機機器翻譯，尚未逐場景校對。補丁涵蓋劇情、介面、道具、技能、圖鑑及讀取舊存檔時的預設角色名。標題圖保留英文商標。

工作表中的來源位置可供日後回填。修改工作表之後，需要將修訂套回遊戲資料並重建補丁。
