# Blood 'n Bikinis 繁體中文補丁

這是 2026-10-10 版本的繁體中文補丁。安裝前請先閱讀同資料夾的 `安裝說明.txt`。

將 `patch_zhTW` 內的四個安裝檔（不含本 README）複製到遊戲資料夾，與 `Game.exe`、`Game.rgssad` 放在一起，然後執行 `安裝繁中補丁.bat`。也可直接下載遊戲資料夾頂層的 `Blood_n_Bikinis_zhTW_patch.zip`，解壓縮到遊戲資料夾後安裝。

安裝程式只接受製作補丁時使用的 Steam 原版 `Game.rgssad`，並在修改前備份原檔。詳細的版本限制與還原步驟請見 `安裝說明.txt`。
