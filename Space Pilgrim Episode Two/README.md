腳本採靜態擷取，實際顯示用途需要對照遊戲。執行時組成的文字、難以辨讀的圖像細字與 Steam 平台文字仍待核對。

## 主選單測試

「開始新遊戲」、「繼續遊戲」、「離開遊戲」已透過 Steam 啟動確認顯示，三個譯文已填入工作表。

![主選單測試截圖](title-menu-test.png)

主選單測試沿用第一集的 `patch-title-menu.cjs`。關閉遊戲後，以安裝資料夾作為第一個參數並加上 `--apply`。還原時，關閉遊戲並以安裝目錄內的 `Game.rgss3a.title-menu-test.bak` 覆蓋 `Game.rgss3a`。

## 重新匯出原文

`export-text.py` 接收遊戲安裝資料夾與輸出 JSON 路徑，優先讀取主選單測試的原始備份，並從 `image-text.tsv` 載入已辨讀的圖像文字。接著以第一集的 `build-workbook.mjs` 將 JSON 轉為 Excel。重匯前請另外保留已填寫的工作表。
