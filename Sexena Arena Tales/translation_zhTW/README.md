## 劇情文字 DUMP

在遊戲根目錄執行 `py -3 translation_zhTW/dump_text.py`，會從未修改的 `resources/app.original.asar` 匯出文字至 `translation_zhTW/dump/`，不會改動遊戲封包或存檔。可使用 `--out-dir` 指定輸出資料夾；使用 `--active-only` 只掃描遊戲頁面實際載入的 `src/Questena.js`。

`story_dump.json` 保存原文、現有譯文、出現次數及所有 Ink JSON 位置，原文內容可無損還原。`story_dump.tsv` 是完整檢視表；`untranslated_active.tsv` 包含尚未翻譯的主劇情字串；`untranslated_text.tsv` 依簡單規則剔除疑似資源名稱與程式指令，方便人工挑選，但此分類可能誤判，請以完整 JSON 為準。`html_dump.tsv` 另外列出 `src/index.html` 的可見文字和常見文字屬性。TSV 的換行與 Tab 用 `\n`、`\t` 顯示；精確原文請看 JSON。

執行 `py -3 translation_zhTW/review_remaining.py` 可重新產生 `dump/remaining_review.tsv`，逐項列出目前保留原文的有效 Ink 字串、分類原因及位置。工具會核對原始 ASAR 的 SHA-256，來源版本改變時須重新審核分類。

新譯文可先寫入 `batches/` 內的 JSON，以 DUMP ID 對應人工譯文，再用 `py -3 translation_zhTW/import_batch.py <批次檔> <輸出 strings_*.json>` 匯入。工具會核對原文及既有譯文，避免重複或錯位。

按場景整理：執行 `py -3 translation_zhTW/scene_worklist.py --list` 查看各場景待譯數；執行 `py -3 translation_zhTW/scene_worklist.py --scene EndingScenes --output translation_zhTW/scene_ending_worklist.md` 匯出同一場景的原文與既有譯文作為上下文。場景表會略過疑似技術字串；專有名稱或短選項仍應查完整 DUMP。

封包中另有四份未由 `src/index.html` 載入的 `Questena.js`。完整 DUMP 也會收錄它們，並以 `archive_only` 標記只出現在這些檔案中的字串。DUMP 不會擷取一般 JavaScript 程式碼裡的任意字面字串。
